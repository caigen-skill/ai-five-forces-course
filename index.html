提示词工程

进入AI世界的第一把钥匙

💡 核心认知

提示词的本质：领导给AI派活的话术

记住：提示词是聊出来的，而非写出来的！

差的领导：「你帮我做个方案」→ 员工完全不知从何入手

好的领导：「针对北京中高收入女性(25-35岁)，做护肤品推广方案...」→ 员工一次命中

提示词能力 = 你作为「AI领导」的管理水平

提示词能力四级分级

L1

零门槛 · 上手快

仅能完成简单问答

无法控制输出质量

解决复杂问题

L2

标准场景输出稳定

依赖模版 · 灵活度差

无法适配非标准化需求

有较高调试成本

L3

体系化解决复杂任务

沉淀可复用资产

真正驾驭AI

无明显能力短板

L4

主动引导大幅提升输出质量

高效解决复杂问题

主动引导AI工作流

📋 L2-RBTO 框架：文生文提示词核心结构

R Role 角色 - 你是一位专业、严谨、有经验的【领域/身份】

B Background 背景资料 - 【这里粘贴背景、上下文、参考资料】

T Task 任务 - 请你完成以下任务：1.【具体任务1】2.【具体任务2】

O Output 输出要求 - 1.语言风格 2.格式要求 3.内容要求 4.字数要求

框架逻辑：谁（Role）基于什么信息（Background）做成一件什么事（Task），要以符合我要求的方式告诉我（Output）

🎨 L2-文生图提示词框架：4W + 风格 + 参数

Who 主体 - 画面主角

Where 场景 - 环境背景

When 时间/光线 - 光线氛围

What 细节 - 服装/动作

Style 风格 - 艺术风格

参数 - 分辨率/比例

高级提示词工作流

🔄 L3-反提示词工作流

逻辑：将优质内容反向输入AI，提炼生成该内容所使用的提示词

步骤：

  1. 找到高质量内容
  2. 使用反提示词指令提炼框架
  3. 获得提示词模板后，替换自己的主题
  4. 用替换后的提示词生成你的专属内容
🤖 L3-元提示词工作流

逻辑：不需要会写专业提示词，只需用大白话说清需求

步骤：

  1. 倒出全部想法（越详细越好）
  2. 让AI生成提示词
  3. 彩排验证与迭代
  4. 输出想要的结果
⛓️ L4-提示词链

逻辑：对于复杂任务拆解成多个步骤

步骤：

  1. 先写prompt A，基于上下文输出output A
  2. 再写prompt B，基于output A输出output B
  3. 再写prompt C，基于output B输出output C
  4. 对提示词链调优，并沉淀为提示词链资产

AI五力模型：KPMEC系统

知识力 × 产品力 × 市场力 × 变现力 × 协同力

📚
第一力：知识力 Knowledge

核心观点：你的专有知识，是AI最好的燃料

AI时代企业真正的护城河不是算力和模型，而是你独有的行业知识、领域理解与专业能力。（黄仁勋）

知识库搭建五步法：

  1. 知识采集 - 已有知识整理 / 录音拍摄采集
  2. 知识分类 - 企业/行业/项目/个人/客户知识
  3. 知识标注 - 每条知识打标签，方便调用
  4. 知识导入 - 云端知识库导入
  5. 知识更新 - 根据时效性更新

AI时代的十大生存法则

基于陈菜根方法论的核心洞察

01
竞争重构 - 对手是"人机协同体"，而非AI

核心逻辑：技术革命消灭的不是职业，而是拒绝进化的人。竞争的本质已从"人与人"或"人与机"转变为"人机协同体"之间的竞争。

行动策略：停止对AI可靠性的纠结，立即掌握AI工具。你的竞争对手是那个已经熟练使用AI的同行。

02
护城河构建 - 隐性知识是AI无法殖民的领地

核心逻辑：AI只能压缩和检索已被语言化的显性知识。你从失败、直觉和行业浸润中获得的"不可言传"的经验，是真正的稀缺资产。

行动策略：系统化你的"踩坑"经历。将那些"说不清楚但就是知道"的直觉和失败案例语言化、结构化。

03
能力升维 - 深度为锚，跨界为网

核心逻辑：AI在单一领域的"够用"能力极强，但缺乏跨域连线的直觉。基于"比较优势"理论，你的价值不在于单一技能的精深，而在于跨界组合的独特性。

行动策略：在一个领域深扎作为锚点，同时在两三个相邻领域建立"够用"的知识。训练"连线直觉"。

04
认知主权 - 注意力是唯一的硬通货

核心逻辑：信息丰富必然导致注意力匮乏。AI使信息生产成本趋近于零，深度专注力成为最稀缺的资源。

行动策略：保护深度阅读与独立思考的能力。在AI拉平生产效率的时代，能长时间专注的人是"认知贵族"。

05
信任溢价 - 信用是唯一的防伪标签

核心逻辑：基于博弈论，信任是重复博弈中"说到做到"的兑现记录。在AI能伪造一切的时代，"真人且靠谱"产生悖论式升值。

行动策略：积累"信号穿透力"。每一次兑现承诺都是在做AI时代最值钱的投资。

06
价值倒转 - 好问题比答案更值钱

核心逻辑：传统教育训练"回答"，AI让答案不再稀缺。5分钟的解答可外包给AI，55分钟的定义问题只能由人完成。

行动策略：培养提问能力。好问题能打开新的可能性空间，而非收窄边界。

07
人类溢价 - 寻找"因为有人，所以值钱"的场景

核心逻辑：人的在场本身正在成为高价值属性。人类是社会性动物，催产素和镜像神经元不响应AI。越是自动化、冰冷的地方，人的温度越值钱。

行动策略：避开纯效率竞争，进入需要情感连接、临终关怀、深度共情或关键决策的领域。

08
反脆弱 - 不确定性是普通人的结构性优势

核心逻辑：基于塔勒布的"反脆弱"理论，大机构在确定性中有优势，但在不确定性中因流程冗余而笨重。普通人的轻量级和灵活性是应对高速变化的利器。

行动策略：小注押注，快速迭代。不要All-in单一判断，建立能吸收错误的生活结构。

09
网络效应 - 持续输出，将认知变为公开资产

核心逻辑：你的公开表达是知识网络的节点。AI降低了内容生产门槛，但也使"独特观点"更稀缺。不输出即不存在，存在才能吸引价值流动。

行动策略：持续输出带有真实经历和独立判断的内容。不是为了表演，而是为了在AI噪音中建立独特节点。

10
能量管理 - 峰值认知用于高价值创造

核心逻辑：时间管理是工业时代的逻辑，能量管理是AI时代的逻辑。高阶认知功能（洞察、创造）依赖前额叶皮层的峰值状态，且每日有限。

行动策略：将最宝贵的"峰值时间"用于思考最重要问题和创造性工作，将低认知成本的任务交给AI。
