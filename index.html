语言篇

提示词工程

进入 AI 世界的第一把钥匙 · 一切上下文、流水线、技能本质都是提示词的扩展。

核心认知

提示词的本质：领导给 AI 派活的话术

提示词是聊出来的，而非写出来的。

差的领导：「你帮我做个方案」→ 员工完全不知从何入手

好的领导：「针对北京中高收入女性(25-35 岁)，做护肤品推广方案，突出成分安全，3 页 PPT，简洁专业」→ 员工一次命中

提示词能力 = 你作为「AI 领导」的管理水平

提示词能力四级分级

L1
零门槛 · 上手快
仅能简单问答
无法控制输出质量
解决复杂问题困难
L2
标准场景输出稳定
依赖模版 · 灵活度差
无法适配非标准化需求
有较高调试成本
L3
体系化解决复杂任务
沉淀可复用资产
真正驾驭 AI
无明显能力短板
L4
主动引导提升输出质量
高效解决复杂任务
主动引导 AI 工作流

L1 → L2 是入门  |  L2 → L3 是进阶  |  L3 → L4 是高手

高级提示词工作流

L3

反提示词工作流

逻辑：将优质内容反向输入 AI，提炼出生成该内容所用的提示词，再以此为模板生成同质量内容。

  1. 找到高质量内容
  2. 使用反提示词指令提炼框架
  3. 替换自己的主题与关键词
  4. 生成你的专属内容

L3

元提示词工作流

逻辑：用 AI 帮你写提示词并生成结果。不需要会写专业提示词，只需用大白话说清需求。

  1. 倒出全部想法（越详细越好）
  2. 让 AI 生成提示词
  3. 彩排验证与迭代
  4. 输出想要的结果

L4

提示词链

逻辑：对于复杂任务拆解成多个步骤，按"输入 → 输出"结构梳理成提示词链。

  1. Prompt A → output A
  2. Prompt B → output B（基于 A）
  3. Prompt C → output C（基于 B）
  4. 沉淀为提示词链资产

五力篇

AI 五力模型 · KPMEC 系统

知识力 × 产品力 × 市场力 × 变现力 × 协同力 —— 基于知识开发产品，产品营销触达用户，品牌驱动促进销售，人机协同放大营收。

知识力 · Knowledge
你的专有知识，是 AI 最好的燃料。AI 时代企业真正的护城河不是算力和模型，而是你独有的行业知识、领域理解与专业能力。（黄仁勋）
知识库搭建五步法
  1. 知识采集 —— 已有知识整理 / 录音拍摄采集
  2. 知识分类 —— 企业 / 行业 / 项目 / 个人 / 客户知识
  3. 知识标注 —— 每条知识打标签，方便调用
  4. 知识导入 —— 云端知识库导入
  5. 知识更新 —— 根据时效性更新
产品力 · Product
产品是你基于 AI 封装的价值。大模型拉平了 Coding 能力，文科生也可以基于 AI Coding 用自然语言开发产品。
AI 产品层级（自下而上）
  • ① 基础设施层 · 大模型 / 算力服务
  • ② 开发工具层 · Agent 框架 / 低代码平台
  • ③ 能力组件层 · Skills / 插件 / API / 知识库
  • ④ 智能代理层 · 通用 / 垂直 / Multi-Agent
  • ⑤ 终端应用层 · AI Native 应用
市场力 · Marketing
用 AI 构建「一人市场部」—— 用多模态树延展创意并积累注意力资产，用多 Agent 分发品牌声量。
一人新媒体部门 = 一人 + 多 Agent
  • 选题策划 Agent · 热点捕捉、选题判断
  • 内容创作 Agent · 脚本撰写、文案优化
  • 视觉制作 Agent · 封面图、配图、视频生成
  • 分发运营 Agent · 多平台发布、评论区管理
  • 数据分析 Agent · 爆款分析、阅读数据
变现力 · Earnings
牢记 AI 使用公式：ROI = 任务价值 / Token 成本。AI 把智能价值封装成可以流动的标准化 Token，正在深刻塑造商业模式结构。
Token：AI Native 智能组织的工时

Token 本质：Token = 电力 × 算力 × 模型智能 = 标准化、可计价、可流通的最小智能服务单位。

Token 全链路成本：电力占 31% · GPU 折旧占 46.5% · 数据中心占 13.5% · 模型占 9%。终端价会比出厂价加 25% - 100%。

总结篇

AI 时代的十大生存法则

技术革命消灭的不是职业，而是拒绝进化的人。

01
竞争重构 —— 对手是"人机协同体"，而非 AI

核心逻辑：竞争的本质已从"人与人"转变为"人机协同体"之间的竞争。

行动：停止对 AI 可靠性的纠结，立即掌握 AI 工具。你的竞争对手是那个已经熟练使用 AI 的同行。

02
护城河构建 —— 隐性知识是 AI 无法殖民的领地

核心逻辑：AI 只能压缩已被语言化的显性知识。你从失败、直觉和行业浸润中获得的"不可言传"的经验，是真正的稀缺资产。

行动：系统化你的"踩坑"经历。将那些"说不清楚但就是知道"的直觉语言化、结构化。

03
能力升维 —— 深度为锚，跨界为网

核心逻辑：基于"比较优势"理论，你的价值不在于单一技能的精深，而在于跨界组合的独特性。

行动：在一个领域深扎作为锚点，同时在两三个相邻领域建立"够用"的知识。训练"连线直觉"。

04
认知主权 —— 注意力是唯一的硬通货

核心逻辑：AI 使信息生产成本趋近于零，深度专注力成为最稀缺的资源。失去专注力即降级为 AI 的"消费终端"。

行动：保护深度阅读与独立思考的能力。能长时间专注的人是"认知贵族"。

05
信任溢价 —— 信用是唯一的防伪标签

核心逻辑：在 AI 能伪造一切的时代，"真人且靠谱"产生悖论式升值。信任是重复博弈中"说到做到"的兑现记录。

行动：积累"信号穿透力"。每一次兑现承诺都是在做 AI 时代最值钱的投资。

06
价值倒转 —— 好问题比答案更值钱

核心逻辑：AI 让答案不再稀缺。5 分钟的解答可外包给 AI，55 分钟的定义问题只能由人完成。

行动：培养提问能力。好问题能打开新的可能性空间，你用问题启动 AI，再用更好的问题挖掘 AI 未想到的方向。

07
人类溢价 —— 寻找"因为有人，所以值钱"的场景

核心逻辑：越是自动化、冰冷的地方，人的温度越值钱。人类是社会性动物，催产素和镜像神经元不响应 AI。

行动：避开纯效率竞争，进入需要情感连接、深度共情或关键决策的领域。问自己：如果全由 AI 做，客户会失去什么？

08
反脆弱 —— 不确定性是普通人的结构性优势

核心逻辑：基于塔勒布的"反脆弱"理论，大机构在不确定性中因流程冗余而笨重，普通人的轻量级和灵活性是应对高速变化的利器。

行动：小注押注，快速迭代。不要 All-in 单一判断，建立能吸收错误的生活结构。

09
网络效应 —— 持续输出，将认知变为公开资产

核心逻辑：AI 降低了内容生产门槛，但也使"独特观点"更稀缺。不输出即不存在，存在才能吸引价值流动。

行动：持续输出带有真实经历和独立判断的内容。不是为了表演，而是为了在 AI 噪音中建立独特节点。

10
能量管理 —— 峰值认知用于高价值创造

核心逻辑：时间管理是工业时代的逻辑，能量管理是 AI 时代的逻辑。高阶认知功能（洞察、创造）每日有限。

行动：将最宝贵的"峰值时间"用于思考最重要问题，将低认知成本的任务交给 AI。你的位置在峰值，不在流水线。
